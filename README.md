# Rajveer Yadav — Task 3 Portfolio

A responsive portfolio built with HTML, CSS, and JavaScript. It showcases About, Work, Skills, Resume, and Contact sections with smooth navigation and a mobile menu. The Daymark task app is a live project; the other work cards are identified as concepts.

## Run
Open index.html in a modern browser. No installation is required. Open resume.html to view or print the resume, then choose “Save as PDF” in the print dialog.

## Files
- index.html — portfolio page
- style.css — responsive design
- script.js — menu behavior and current year
- resume.html — printable resume

Personal email and phone are omitted; the Contact section links to the public GitHub profile.
